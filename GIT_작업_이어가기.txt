====================================================================
 프로게이머 커리어 — 여러 PC에서 작업 이어가기 (git 안내)
====================================================================
저장소: https://github.com/stlemm-rgb/lolst-pro   (브랜치 master)
웹 주소: https://stlemm-rgb.github.io/lolst-pro/   (push 1분쯤 뒤 자동 반영)
게임 폴더: C:\Project\Game\Game   (모든 PC에서 같은 경로 권장)
명령은 모두 PowerShell(또는 VS Code 터미널)에 한 줄씩 붙여 넣기.

--------------------------------------------------------------------
 [A] 작업을 끝낼 때 (지금 PC) — 매번
--------------------------------------------------------------------
cd C:\Project\Game\Game
git add -A
git commit -m "ver 1.1: 오늘 바꾼 내용을 한 줄로"
git push

 * 버전을 올렸을 때만 (예: ver 1.2 완성):
git tag v1.2
git push --tags          ← git push만으로는 태그가 안 올라감

 * "nothing to commit" 이 나오면: 바뀐 게 없음 → git push만 해도 됨
 * push가 rejected(거부)되면: 다른 PC에서 먼저 올린 게 있음
git pull
git push

--------------------------------------------------------------------
 [B] 다른 PC에서 처음 한 번만 (준비)
--------------------------------------------------------------------
1) Git 설치: https://git-scm.com/download/win  (설치 옵션은 기본값 그대로 Next)
2) 설치 후 PowerShell을 새로 열고 내 이름·메일 등록 (한 번만)
git config --global user.name "stlemm"
git config --global user.email "stlemm@gmail.com"
git config --global core.autocrlf true
3) 게임 내려받기 (폴더 이름을 Game으로 → C:\Project\Game\Game 이 됨)
mkdir C:\Project\Game
cd C:\Project\Game
git clone https://github.com/stlemm-rgb/lolst-pro.git Game
cd Game
git log --oneline -3      ← 최신 커밋이 보이면 성공
4) 처음 git push 할 때 GitHub 로그인 창이 뜨면 로그인 (한 번만)

--------------------------------------------------------------------
 [C] 다른 PC에서 작업 시작할 때 — 매번
--------------------------------------------------------------------
cd C:\Project\Game\Game
git pull
 → "Already up to date." 또는 바뀐 파일 목록이 나오면 준비 끝.
 → 작업이 끝나면 다시 [A].

--------------------------------------------------------------------
 [D] 순서 요약 (PC 두 대: 집 / 회사 예시)
--------------------------------------------------------------------
 집에서 작업 → [A] add · commit · push
 회사 도착   → [C] pull → 작업 → [A] add · commit · push
 집 도착     → [C] pull → 작업 → ...
 ※ 한 번에 한 PC에서만 작업. push 안 하고 다른 PC로 가면 내용이 안 넘어감.

--------------------------------------------------------------------
 [E] 문제가 생기면
--------------------------------------------------------------------
1) git pull 했는데 "Your local changes ... would be overwritten" 이 나옴
   (이 PC에서 고치고 커밋 안 한 게 있음)
   → 이 PC 변경을 살리려면:  git add -A  →  git commit -m "임시 저장"  →  git pull
   → 이 PC 변경을 버려도 되면:  git stash  →  git pull
2) "CONFLICT" (충돌)이 나옴 → 더 진행하지 말고 화면을 AI에게 보여 주기
   (두 PC에서 같은 파일을 따로 고쳤을 때 생김)
3) 무엇이 바뀌었는지 보기:  git status   /  최근 기록 보기:  git log --oneline -10
4) 게임 세이브는 git으로 안 넘어감 (브라우저에 저장됨)
   → 게임 [설정] → 세이브 내보내기 → 파일을 다른 PC로 옮겨 → 세이브 가져오기

--------------------------------------------------------------------
 [F] AI(Claude Code·Cowork·Codex)에게 작업 이어서 시키기
--------------------------------------------------------------------
 [C]로 pull 한 다음, 이렇게 말하면 됨:
 "HANDOFF.md → PROGRESS.md 마지막 항목들 → CLAUDE.md 순서로 읽고,
  git status로 상태 확인부터 해 줘. 그다음 HANDOFF 7장 로드맵 다음 순서 진행."
 (커밋은 내가 직접 → AI가 답 끝에 [A] 명령을 알려 줌)
