==================== 아래 전부를 복사해서 다른 AI에게 붙여 넣으세요 ====================

나는 롤(리그 오브 레전드) 프로게이머 커리어 게임을 만들고 있어.
게임 안의 "선수 SNS" 화면에 올라오는 짧은 글을 써 줘.
플레이어가 키우는 프로게이머(내 선수)에게 무슨 일이 생기면, 그 상황에 맞는 글이 무작위로 하나씩 올라와.

■ 써 줄 것: 두 종류
  [A] 팬 글: 커뮤니티 댓글 말투. 반말, 'ㄷㄷ', 'ㅋㅋ', 'ㅠㅠ' 같은 인터넷 말투 OK. 칭찬·응원·아쉬움·드립 골고루.
      분류마다 15개.
  [B] 프로 선수 글: 같은 리그 다른 팀 프로 선수가 쓰는 글. 존댓말, 상대에 대한 존중.
      욕설·비꼼·조롱·'ㅋㅋ' 남발 금지. 분류마다 12개 (streaming·sponsor는 6개).

■ 분류 (상황)
  winStreak   우리 팀이 이번 주에 이겨서 3연승 이상이 됐을 때
  streakBreak 3연패 이상 하다가 이번 주에 드디어 이겼을 때 (연패 탈출)
  superPlay   이번 주 경기에서 내 선수가 슈퍼플레이(혼자 판을 뒤집는 큰 활약 장면)를 했을 때
  blunder     이번 주 경기에서 내 선수가 큰 실수를 했을 때 (팬은 아쉬움·걱정·가벼운 비판, 심한 악플은 빼기)
  promoted    우리 팀이 2부 리그에서 1부 리그로 승격했을 때
  relegated   우리 팀이 1부 리그에서 2부 리그로 강등됐을 때
  benchReturn 내 선수가 2군에 있다가 주전으로 돌아왔을 때
  transfer    내 선수가 다른 팀으로 이적했을 때
  renewal     내 선수가 지금 팀과 재계약했을 때
  award       내 선수가 개인상(시즌 MVP, 올프로, 신인왕, 결승 MVP 등)을 받았을 때
  ladderTop   내 선수가 리그 솔로 랭크 1위를 찍었을 때 (또는 '솔랭 1위' 칭호를 받았을 때)
  streaming   내 선수가 개인 방송을 하고 있을 때 (방송 내용·채팅·소통 이야기)
  sponsor     내 선수가 스폰서 광고 계약을 하고 있을 때 (광고·화보·협찬 이야기)

■ 빈칸 표시 (게임이 알아서 채움). 중괄호까지 그대로 쓰기
  {name}    내 선수 이름 (예: Faker). 들어간 글은 "내 선수를 언급한 글"로 알림이 떠. 분류마다 절반 이상은 {name}을 넣어 줘
  {team}    내 선수의 팀 이름 (예: T1 PHOENIX). transfer에서는 '새 팀'
  {pos}     내 포지션 (탑·정글·미드·원딜·서포트)
  {opp}     이번 주 상대 팀 이름 (winStreak·streakBreak·superPlay·blunder에서만 사용)
  {streak}  숫자만 들어감. winStreak = 연승 수, streakBreak = 끊은 연패 수 (예: '{streak}연승', '{streak}연패 끝')
  {oldteam} 전 소속팀 이름 (transfer에서만 사용)
  {award}   상 이름 (award에서만 사용, 예: '시즌 MVP')
  {proteam} 글을 쓴 프로 선수 자신의 팀 이름 ([B] 프로 선수 글에서만, 예: '저희 {proteam}도 더 준비하겠습니다')

■ 꼭 지킬 규칙
  1. 글 하나는 한 줄, 30~60자 정도로 짧게
  2. 글 안에 큰따옴표(")를 쓰지 말 것. 필요하면 작은따옴표(')나 「」 사용
  3. 빈칸 바로 뒤에 받침에 따라 바뀌는 조사(이/가, 을/를, 은/는, 와/과, 으로/로)를 붙이지 말 것.
     이름이 영어일 수도, 한글일 수도 있어서 어색해짐
     - 나쁜 예: {name}가 캐리했다 / {team}이 이겼다
     - 좋은 예: {name} 오늘 캐리했다 / {name}의 플레이 / {team} 선수들 / {team}도 / {name} 선수가
  4. 실존 인물·실제 팀 이름, 욕설, 특정인 비방 금지 (빈칸만 사용)
  5. 분류 안에서 비슷한 문장이 반복되지 않게, 상황 묘사를 다양하게
  6. 각 분류의 상황에서만 말이 되는 글로 쓸 것 (예: transfer 글에 '우승'이야기 X)

■ 답변 형식: 아래 모양 그대로, 코드 블록 2개로만 답해 줘 (설명은 필요 없음)

```js
// [A] 팬 글
  winStreak: [
    "글",
    "글",
  ],
  streakBreak: [
    "글",
  ],
  (… sponsor까지 13개 분류 모두)
```

```js
// [B] 프로 선수 글
  winStreak: [
    "글",
  ],
  (… sponsor까지 13개 분류 모두)
```
