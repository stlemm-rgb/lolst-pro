# 팬 수 돌파 공중파 뉴스 기사 작성 요청 (다른 AI용)

아래 규칙대로 **JavaScript 코드만** 써 주세요. 설명 글은 필요 없어요.

## 게임 소개 (짧게)
한국어 텍스트 e스포츠 선수 커리어 게임. 내 선수(프로게이머)의 팬 수가 1,000만 / 5,000만 / 1억 명을 처음 넘으면
'공중파 뉴스에 나왔다'는 신문 기사 팝업이 하나 떠요.

## 만들 것
`FAN_MILESTONES` 배열 전체. 단계마다 `articles`에 기사 **4개씩** (지금 있는 1개 포함해서 새로 4개 써도 됨).

```js
const FAN_MILESTONES = [
  { at: 10000000, label: "1,000만", icon: "📺", articles: [
    { headline: "...", body: "..." },
    // 4개
  ] },
  { at: 50000000, label: "5,000만", icon: "📡", articles: [ /* 4개 */ ] },
  { at: 100000000, label: "1억", icon: "🌐", articles: [ /* 4개 */ ] },
];
```

## 규칙
- headline: 25자 안쪽, 맨 앞에 그 단계 icon(📺/📡/🌐) 하나.
- body: 2~4문장. '공중파 뉴스(저녁 뉴스·9시 뉴스·특집·다큐·예능 출연 등)에 나왔다'는 내용이 꼭 들어갈 것.
- 단계마다 분위기 차이: 1,000만 = 놀라움·화제 / 5,000만 = 국민 스타·사회 현상 / 1억 = 세계적 아이콘·역사.
- 쓸 수 있는 빈칸 (그대로 쓰면 실제 값으로 바뀜):
  - `{me}` 선수 이름, `{myTeam}` 소속 팀, `{pos}` 포지션(탑·정글·미드·원딜·서포트)
  - `{fans}` 지금 팬 수 (예: "1,005만 명" — 항상 '명'으로 끝남 → 뒤에 조사는 '을', '이')
  - `{year}` 연도, `{titles}` 우승 기록 한 문장 (예: "우승 기록: 월드 2회 · 리그 3회." 우승이 없으면 빈칸) — 문장 맨 끝에만 쓰기
- 이름 뒤 조사는 받침을 모르니 `을(를)`, `이(가)`, `은(는)`, `과(와)`, `(으)로` 형태로.
- 큰따옴표 `"` 대신 작은따옴표 `'` 사용 (코드가 깨지지 않게).
- 실제 방송사 이름(KBS·MBC·SBS 등)·실존 인물 이름은 쓰지 말 것 ('공중파', '한 방송사' 정도로).
