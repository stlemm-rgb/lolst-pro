### 빈칸 규칙 (틀리면 게임 화면에 `{opp}`가 글자 그대로 보여)

| 빈칸 | 뜻 | 쓸 수 있는 분류 |
|---|---|---|
| `{name}` | 내 선수 이름 | 모든 분류 |
| `{team}` | 내 팀 이름 (transfer에서는 새 팀) | 모든 분류 |
| `{pos}` | 내 포지션 (탑·정글·미드·원딜·서포트) | 모든 분류 |
| `{opp}` | 이번 주 상대 팀 | win · loss · winSweep · winClose · lossSweep · lossClose · soloKill · winStreak · streakBreak · superPlay · blunder **만** |
| `{champ}` | 이번 패치 S급 메타 챔피언 | patch **만** |
| `{cup}` | 우승한 대회 이름 | champion **만** |
| `{streak}` | 숫자만 (연승·끊은 연패 수) | winStreak · streakBreak **만** (예: '{streak}연승') |
| `{oldteam}` | 전 소속팀 | transfer **만** |
| `{award}` | 상 이름 | award **만** |
| `{proteam}` | 글을 쓴 프로 선수 자신의 팀 | **프로 글 파일만** |

- 위 목록에 없는 빈칸은 만들지 마.
- 빈칸 뒤 조사는 이름 받침에 따라 어색해져. '{name}이/가', '{team}은/는/을/를'은 쓰지 말고, '도', '와 함께', '의', '선수', '팬들'처럼 받침과 상관없는 말을 붙여.

### 글 쓰는 규칙

**형식**
- 글 하나 = 큰따옴표로 감싼 한 줄 + 끝에 쉼표.
- 글 안에 큰따옴표(")와 줄바꿈 금지. 필요하면 작은따옴표(')나 「」를 써.
- 파일 줄바꿈은 지금처럼 **CRLF**, 글자는 UTF-8 그대로.

**말투**
- **팬 글**: 커뮤니티 댓글 말투. 반말, 'ㄷㄷ'·'ㅋㅋ'·'ㅠㅠ' 같은 인터넷 말투 OK. 칭찬·응원·아쉬움·드립·분석·직관 후기를 골고루. 평균 30자 안팎(10~60자).
- **프로 선수 글**: 같은 리그 다른 팀 선수. 존댓말, 상대를 존중. 욕설·비꼼·조롱·'ㅋㅋ' 남발 금지. 평균 40자 안팎.

**금지**
- 욕설, 혐오, 성적인 내용, 실존 인물·실존 팀 비방.
- 실존 프로게이머 이름, 실제 경기 결과, 2027년 이후 가짜 역사.
- 상황에 안 맞는 글. 예: loss에 이긴 이야기, rookie에 베테랑 이야기, train_rest에 경기 이야기.

**다양하게 (이번 작업의 목적)**
- 게임에서 같은 문장이 여러 선수 이름으로 반복돼 보이는 문제를 줄이려는 거야. **기존 글이나 새 글끼리 거의 같은 문장은 금지.** 단어 하나만 바꾼 글도 피해.
- 같은 분류 안에서 첫 단어와 말끝을 다양하게. 질문형·감탄형·짧은 한마디·긴 후기를 섞어. 밈은 과하지 않게.
- 프로 글은 '수고하셨습니다' 같은 상투 표현이 많아. 구체적인 장면(밴픽, 라인전, 한타, 오브젝트, 스크림, 리플레이)을 말하는 글을 늘려.

## 2번 일: 웃긴 해프닝 60개 (`data/mishaps.js`의 `MISHAPS` 배열 채우기)

게임 결과와 관계없는 **우스꽝스러운 사건사고**야. 대략 4주에 한 번 SNS 피드에 '😂 해프닝' 글로 올라오고, 숙소 해프닝은 방 그림에 소품(고양이·피자 상자·라면 그릇)이 나와. 파일 맨 위 주석 형식을 지켜.

| 장소 (place) | 개수 | 예시 |
|---|---|---|
| 숙소 | 20 (그중 prop: cat 4 · pizza 4 · ramen 4) | 라면 물 조절 실패로 '라면 수프' 탄생 / 길고양이가 키보드를 밟아 채팅창에 'ㅁㄴㅇㄹ' / 민트초코 피자를 잘못 시켰는데 다 먹음 |
| 경기장 | 12 | 인터뷰 때 마이크를 거꾸로 들고 30초 말함 / 엘리베이터에 10분 갇혔는데 그 사이 밴픽 회의를 끝냄 / 단체 사진 12장 중 11장에서 눈 감음 |
| 방송 | 10 | 방송 중 어머니가 '밥 먹어' → 시청자 2만 명이 '네' / 마이크 끈 줄 알고 노래 → 클립 조회 수가 하이라이트보다 많음 |
| 팬 | 10 | 응원 플래카드 이름 철자가 틀렸는데 본인이 인증 / 팬 도시락에 '체력 +10'이라고 적혀 있음 (실제 효과 없음) |
| 동료 | 8 | 같이 PC방 갔는데 둘 다 지갑을 놓고 옴 / 스크림 끝나고 치킨을 우리 팀 몫까지 먹음 |

- 해프닝 하나 = `{ id: "ramen_soup", place: "숙소", prop: "ramen", fan: "...", pro: "..." },`
- **id**: 영어 소문자와 _ (겹치면 안 됨).
- **fan**: 팬이 쓰는 글 (반말·커뮤니티 말투, 20~60자). 꼭 있어야 해. 60개 중 **70% 이상에 {name}**을 넣어 (내 선수 이야기라서).
- **pro**: 다른 팀 프로 선수가 쓰는 글 (존댓말, 30~60자). 60개 중 절반쯤만 쓰고 나머지는 `""`. 동료 장소 8개는 모두 pro 글이 있어야 해.
- **prop**: 숙소 해프닝에서만. 그 소품이 실제로 방에 있을 만한 이야기일 때만 "cat"·"pizza"·"ramen", 나머지는 `null`.
- 빈칸은 `{name}`과 `{team}`만. 큰따옴표 금지. SNS 글과 같은 문장 금지.
- **웃기지만 아무도 다치지 않고, 경기력·스탯·돈이 바뀐 것처럼 읽히지 않게.** ('손목을 다쳐서', '벌금', '그래서 경기에 졌다' 같은 내용 금지.) 실존 인물·실존 브랜드 이름·욕설·혐오·성적인 내용 금지.
