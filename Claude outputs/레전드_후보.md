# ① 네임드 선수 정리 — 레전드 후보 (2026-11-03)

- 실제 LCK 레전드 → 게임 이름은 실제 닉네임에서 **1글자만 바꿈**.
- 데뷔 연도·팀·은퇴 연도는 Claude 기억 기준. **⚠️ = 확인 필요** (틀릴 수 있음). 현역 = 게임에서는 나이에 맞춰 자연 은퇴.
- 게임 팀: 실제 데뷔 팀이 게임에 있으면 그 팀 (Samsung → GEN.G, Afreeca → KW, DAMWON → Dplus). 없으면 '비슷한 강팀'(무작위 강팀).
- 등급: S = 월즈 우승·리그 최고 수준 / A = 리그 정상급.
- ★ = 추천 20명 (포지션 4명씩, 시대 8 · 7 · 5).
